# api-webchat-v2

Современное веб-приложение для чата с архитектурой микросервисов, построенное на FastAPI и WebSocket.

## Описание

Это полнофункциональное чат-приложение с поддержкой:
- Регистрации и аутентификации пользователей
- Создания и управления чат-комнатами
- Реального времени обмена сообщениями через WebSocket
- Поиска по чатам
- Современного веб-интерфейса

## Архитектура

Проект построен на микросервисной архитектуре с использованием Docker:

### Компоненты системы

- **`website/`** - Основной веб-сервис (FastAPI)
  - Аутентификация и авторизация
  - Управление пользователями и чатами
  - Веб-интерфейс (HTML/CSS/JavaScript)
  - REST API для фронтенда

- **`chat/`** - WebSocket сервис чата (FastAPI)
  - Обработка WebSocket соединений
  - Распространение сообщений в реальном времени
  - Управление активными подключениями

- **`nginx/`** - Веб-сервер и прокси
  - Балансировка нагрузки
  - Проксирование запросов к сервисам
  - Обработка WebSocket соединений

- **`db/`** - База данных PostgreSQL
  - Хранение пользователей и чатов
  - Персистентность данных

## Быстрый старт

### Предварительные требования

- Docker
- Docker Compose

### Установка и запуск

1. **Клонируйте репозиторий**
   ```bash
   git clone <repository-url>
   cd api-webchat-v2
   ```

2. **Соберите и запустите контейнеры**
   ```bash
   docker-compose build
   docker-compose up -d
   ```

3. **Откройте приложение**
   ```
   http://localhost
   ```

### Остановка приложения

```bash
docker-compose down
```

## Использование

### Регистрация и вход

1. Откройте приложение в браузере
2. Нажмите "Зарегистрироваться" для создания аккаунта
3. Войдите с помощью email и пароля

### Создание чата

1. После входа перейдите в раздел "Мои чаты"
2. Нажмите "Создать новый чат"
3. Введите название чата
4. Нажмите "Создать"

### Участие в чате

1. Выберите чат из списка
2. Введите сообщение в поле ввода
3. Нажмите Enter для отправки

### Поиск чатов

1. В разделе "Мои чаты" используйте поиск
2. Введите название чата для поиска
3. Результаты отобразятся в реальном времени

## Конфигурация

### Переменные окружения

#### База данных (PostgreSQL)
- `POSTGRES_USER=user` - пользователь БД
- `POSTGRES_PASSWORD=password` - пароль БД
- `POSTGRES_DB=chat_db` - название БД

#### Веб-сервис
- `DB_USER=user` - пользователь для подключения к БД
- `DB_PASSWORD=password` - пароль для подключения к БД
- `DB_NAME=chat_db` - название БД

### Порт-маппинг

- **80** - Nginx (основной веб-сервер)
- **5432** - PostgreSQL (внутренний доступ)

## API Документация

### Веб-сервис (website)

#### Аутентификация
- `POST /login` - Вход в систему
- `POST /logout` - Выход из системы
- `POST /register` - Регистрация нового пользователя

#### Чаты
- `GET /chats` - Список чатов пользователя
- `GET /chats/create` - Страница создания чата
- `POST /chats/create` - Создание нового чата
- `POST /chats/{chat_id}/delete` - Удаление чата
- `GET /chat/{room_name}` - Страница чата
- `GET /chats/search` - Поиск чатов

#### API
- `GET /api/chat/{room_name}/exists` - Проверка существования чата
- `GET /get_chat_token/{room_name}` - Получение токена для WebSocket

### WebSocket сервис (chat)

#### WebSocket соединения
- `WS /ws/{room_name}` - Подключение к чату

#### REST API
- `POST /ws/{room_name}/close` - Закрытие чата
- `POST /ws/{room_name}/broadcast` - Отправка сообщения
